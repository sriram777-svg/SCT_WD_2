# Task 01 – Responsive Landing Page 🌐

This project is created as part of the **Web Development Internship at SkillCraft Technology**.  
The task focuses on building a **responsive landing page** with a **fixed navigation bar** that changes style on scroll and includes interactive hover effects.

---

## 📌 Project Overview

The Responsive Landing Page demonstrates:
- A fixed top navigation bar
- Navbar background change on scroll
- Hover effects on navigation links
- Fully responsive layout using CSS media queries
- Clean and structured frontend code

---

## 🛠️ Technologies Used

- **HTML5** – Page structure
- **CSS3** – Styling, layout, responsiveness
- **JavaScript** – Scroll-based navbar interaction
- **Browser** – Chrome / Firefox / Edge
